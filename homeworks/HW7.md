# Домашние задание №7

## Микромасштабное моделирование с ENVI-met

В рамках задания необходимо:

- Выбрать по данным метеорологических наблюдений для вашего города день для моделирования. Рекомендуется выбирать летний день с умеренной скоростью ветра и минимальной облачность.

- Подготовить конфигурацию ENVI-met для выбранного района города с помощью Spaces или плагина для QGis. Учитывайте ограничения бесплатной версии модели (не более 50*50 ячеек сетки). Рекомендуется задавать шаг сетки не более 10 м. Необходимо задать реалистичную (без фанатизма) конфигурацию зданий, деревьев, типов подстилающей поверхности на основе данных OpenStreetMap и/или Overture Maps (можно использовать результаты [домашнего задания №5](https://github.com/mvarentsov/UClim4HSE-2025/blob/main/homeworks/HW5.md). Этажность необходимо также задать реалистично, путем добавления переменной в атрибутивную таблицу QGis, на основе данных об этажности (доступны для части зданий при скачивании через osmnx) или вручную в Spaces. Вариант с заданием высоты константным значением не принимается.  

- Провести контрольный численной эксперимент с моделью для периода продолжительностью 3 часа начиная с 12:00 в пределах выбранного дня с метеорологическим форсингом по данным наблюдений (с учетом ограничений бесплатной версии модели по его заданию). При желании вместо наблюдений можно использовать реанализ. 

- Провести дополнительный эксперимент для того же периода и с таким же форсингом, но с изменением свойств городской среды (например, добавление деревьев и других видов озеленения, добавлением новых зданий, изменение высоты/формы/материалов существующих - дайте волю творчеству).

- Подготовить описание экспериментов и результатов моделирования (в формате Word/PDF). Оно должно включать:
  - Особенности выбранного для моделирования дня
  - Визуализацию области моделирования, краткое пояснение, как задавались параметры застройки и поверхности
  - Описание дополнительного эксперимента (что менялось относительно контрольного)
  - Визуализацию приземной (на высоте 1.5-2 м) температуры и скости ветра для контрольного эксперимента, их интерпретацию
  - Визуализацию и интерпретацию результатов дополнительного эксперимента и его сравнения с контрольным.
